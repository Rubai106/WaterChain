# Archived development and verification history

This folder contains earlier step-by-step changelogs, bug-fix summaries, release audits, and verification snapshots moved from the repository root to reduce clutter.

These records are preserved for provenance and to explain how the implementation evolved. **They are historical snapshots, not the current project status.** For current setup and operation, use [the startup guide](../../STARTUP_GUIDE.md). For the current implementation and limitations, use [the project README](../../README.md). For the current evidence, use [the Step 20 test report](../../TEST_REPORT_STEP20.md), [evidence summary](../../validation/STEP20_EVIDENCE_SUMMARY.md), and [scorecard](../../STEP20_SCORECARD.md).

Archived files:

- Browser and regression-test reports from earlier releases.
- Consolidated and per-step bug-fix summaries.
- Step 9–16 changelogs, release audits, verification records, and the Step 12 product-foundation snapshot.
- Step 19 changelog and older general/Step 10/Step 18 test reports.
- Redesign/refinement changelogs and test reports.
- Prior readiness assessment and release reconciliation.

Older reports may describe tests that were blocked in their original environment or have since been superseded. Read the date, scope, and limitations within each report before relying on a result.
