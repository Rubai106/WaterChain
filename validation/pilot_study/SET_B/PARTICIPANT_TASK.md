1. Identify the core documented journey and any record that should not be treated as part of it without further evidence.

4. Give up to three next actions, each tied to a verifiable evidence gap.
5. Submit the response form and stop the timer.

Use the same time limit and instructions whichever workflow is assigned. The facilitator may explain interface mechanics but must not explain the expected decision or direct attention to a particular record.
